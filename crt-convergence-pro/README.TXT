CONTENTS:

This CD-ROM contains professional-grade test patterns for calibrating and
diagnosing CRT monitors, LCD displays, and modern screens.

QUICK START (Windows 98/XP):
-----------------------------
1. Insert this CD-ROM into your computer
2. The menu should auto-launch (if not, open MENU.HTML)
3. Select a test pattern from the menu
4. Press F11 for fullscreen mode
5. Use keyboard controls to navigate patterns

QUICK START (Modern Windows):
------------------------------
1. Open MENU.HTML in your web browser
2. Select a test pattern
3. Press F11 for fullscreen
4. Follow on-screen instructions

RECOMMENDED CRT SETTINGS:
-------------------------
* Resolution: 800x600 or 1024x768
* Refresh Rate: 75Hz or higher
* Color Depth: 32-bit

WHAT IS CONVERGENCE?
--------------------
CRT convergence is the alignment of red, green, and blue electron beams.
Proper convergence creates sharp, white lines. Poor convergence shows
separate RGB colors and causes blurry images.

TROUBLESHOOTING:
----------------
* If autorun doesn't work: Manually open MENU.HTML
* If patterns look wrong: Try a different resolution
* For CRTs: Adjust refresh rate to at least 75Hz
* Modern displays: Disable scaling/smoothing features
